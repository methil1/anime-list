# スマホにインストールする（PWA / アプリ化）

アニメモ！はPWA対応済みなので、**スマホのホーム画面にアプリとして追加**できる。
（ブラウザのタブではなく、独立したアプリのように全画面で起動・オフラインでも起動可能。）

> ⚠️ 前提: この機能は `manifest.webmanifest` と `sw.js` が **公開サイト(main)に反映されている**ことが必要。
> PR #1 を main にマージし、GitHub Pages のデプロイが完了してから実施する。
> 反映確認: スマホ or PC で `https://methil1.github.io/anime-list/manifest.webmanifest` が開ければOK。

---

## Android（Chrome）

1. Chrome で https://methil1.github.io/anime-list/ を開く
2. 右上メニュー ⋮ →「**アプリをインストール**」または「**ホーム画面に追加**」
   - 自動で下部にインストールバナーが出ることもある
3. 確認 →「インストール」
4. ホーム画面に「アニメモ」アイコン（紫の再生マーク）が追加される
5. アイコンから起動 → URLバー無しの全画面で立ち上がる。一度開けば機内モードでも起動可能

## iPhone / iPad（Safari）

1. Safari で https://methil1.github.io/anime-list/ を開く（※iOSはSafari必須。ChromeからはNG）
2. 共有ボタン（□に↑）→「**ホーム画面に追加**」
3. 名前を確認して「追加」
4. ホーム画面のアイコンから全画面起動

> iOS はホーム画面追加でスタンドアロン起動・SWキャッシュは効くが、
> バックグラウンド更新やストレージ上限など一部制限あり。視聴記録は端末内 localStorage に保存。

---

## 注意: 端末ごとにデータは別

視聴記録は各端末の `localStorage` に保存されるため、**PCとスマホでデータは自動同期されない**。
移したい場合は当面、PC側の「視聴履歴を書き出し（JSON）」→ スマホ側で「読み込み」で移行する。
（将来的にクラウド同期を入れるなら別途対応が必要。）

---

## APK（ストア配布/ネイティブアプリ）で入れたい場合

TWA で APK/AAB を生成して入れる方法は `docs/android-twa.md` を参照（手元PCでのビルドが必要）。
「ホーム画面に追加」で十分なら、こちらは不要。
